# RepoArchitect

RepoArchitect is a full-stack software architecture analysis platform that helps developers understand unfamiliar Python codebases. It performs static analysis using Python Abstract Syntax Trees (ASTs), builds dependency graphs, calculates code quality metrics, detects architectural issues, and generates AI-powered summaries to provide an interactive view of a repository's structure.

## Tech Stack

- Python
- FastAPI
- React
- TypeScript
- PostgreSQL
- SQLAlchemy
- Alembic
- Podman
- Google Cloud Run
- Gemini API
